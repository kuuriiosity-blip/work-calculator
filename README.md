# Work Calculator

A simple Python program that calculates payment and remaining money after expenses.

## Features

- Calculate payment from hours worked and hourly rate.
- Subtract expenses.
- Display a positive, zero, or negative balance.

## Requirements

- Python 3

## How to run

Open a terminal in the project folder and run:

```bash
python main.py
```

Enter hours worked, hourly rate, and expenses.
Use a dot for decimal numbers, for example: 6.5.

## Example

- Hours worked: 6
- Hourly rate: 300 CZK
- Expenses: 200 CZK
- Remaining money: 1600 CZK

## Current limitations

The program expects numeric input. Input validation is not implemented yet.
